# Privacy

bauhaus-digital is a Claude Code plugin made of one skill: Markdown instructions and reference notes. It has no scripts, no server, no account and no telemetry.

- **What it reads:** nothing on its own. Claude reads the skill's own files when the skill is used, plus whatever you share in the conversation (screenshots, code, design files).
- **What it writes:** nothing on its own. Any file Claude writes while using the skill is part of your normal Claude session.
- **What it runs:** nothing. The plugin contains no executable code.
- **What it sends:** nothing, to anyone. What Claude itself sends to Anthropic is governed by Anthropic's terms and privacy policy, not by this plugin.

Questions or reports: https://github.com/lucasgpinheiro-rgb/bauhaus-digital/issues
